Aula Inteligente - Sistema IoT

Sistema de control en tiempo real basado en eventos usando WebSockets.

Dependencias
            Flask==3.0.3
            Flask-SocketIO==5.3.6
            python-engineio==4.9.1
            python-socketio==5.11.2

Activar Entorno Virtual

            Windows (PowerShell):
            .\venv\Scripts\activate

            Windows (CMD):
            venv\Scripts\activate.bat

            Linux / Mac:
            primero: python3 -m venv venv

            segundo: source venv/bin/activate

Instalacion

            pip install -r requirements.txt

Ejecucion

            python app.py

            Acceso web: http://localhost:5000
